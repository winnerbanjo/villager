# Edaà 2010 — The Birth of Etu Ofi Jeans

An archival heritage & lookbook website telling the story of OjuInu, Aso-Ofi craftsmanship, and the patent of Etu Ofi Jeans in 2010.

## Features
- **Editorial Design**: High-contrast, classic fashion typography & deep maroon brand aesthetic.
- **YouTube Hero Integration**: Auto-playing video header.
- **71024 Lookbook Gallery**: Interactive image showcase with lightbox modal view.
- **Scroll Micro-Animations**: Smooth IntersectionObserver transitions.

## Tech Stack
- HTML5
- CSS3 (Vanilla)
- JavaScript (ES6+)

## Deployment & Local Setup
To run locally:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.
